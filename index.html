首次配置

把 Mac 上的两样东西装进手机：签名私钥（~/.config/emhcho-license/seed.hex 里那 64 个字符）和一个只带 gist 权限的 GitHub 令牌。保存时会用你设的 PIN 加密。

你选的是「私钥进手机」方案：手机丢失、被云备份、被反编译、被人拿在手上 30 秒，私钥都可能泄露；一旦泄露对方能永久签发授权，补救只能全网换公钥重发牌。请务必：关掉这个 App 的云备份、每次都锁 PIN、令牌只给 gist 权限。

保存前会读令牌的权限范围：除 gist 外还带别的权限（repo / admin / delete…）的令牌一律拒收——Mac 上那把全权限令牌不要贴进来。fine-grained 令牌不支持 gist，要用 classic。

口令是手机里私钥保险箱的唯一屏障：6 位纯数字只挡得住顺手翻手机的人，挡不住把数据拷走离线暴力破解的人。建议 10 位以上、字母数字混合。

保存前会先用 seed 推公钥、和上面的期望公钥比对；不一致不会保存。令牌会先向 GitHub 试读一次这个 gist，并核对权限范围只有 gist。
